# Status legend

| Tag | Meaning |
| --- | --- |
| <span class="status status-verified">VERIFIED</span> | Confirmed in source/config during audit |
| <span class="status status-partial">PARTIAL</span> | Present but incomplete, drifted, or risky |
| <span class="status status-unused">UNUSED</span> | Code exists; not on the live path |
| <span class="status status-notfound">NOT FOUND</span> | No evidence — do not invent in docs |

When updating pages after code changes, **preserve** these tags unless new evidence upgrades or downgrades the claim.
